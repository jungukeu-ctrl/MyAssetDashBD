## 5. 매매 입력 모달 명세

버튼: `[매매입력]` 클릭 시 모달 오픈

```
┌──────────────────────────────┐
│    제일일렉트릭 매매 입력     │
├──────────────────────────────┤
│ 구분:  [매수] [매도]          │
│ 단가:  [________] 원         │
│ 비중:  [____] % (1주=0.6%)   │
├──────────────────────────────┤
│ 예상 결과:                    │
│ • 평단: 11,960 → 11,800원    │
│ • 비중: 0.6% → 1.2%         │
│ • 일 잔여한도: 3.4% → 1.4%  │
├──────────────────────────────┤
│ 메모: [__________________]   │
│          [취소]  [확인]       │
└──────────────────────────────┘
```

### 입력 시 자동 계산
- 매수: 새 평단 = (기존수량×기존평단 + 매수수량×단가) / (기존수량+매수수량)
- 매도: 실현손익 = (매도단가 - 평단) × 수량
- 일 잔여한도: 슬롯(200만) × 4% - 당일매수금액 + 당일매도금액

### 유효성 검사
- 일 한도 초과 시 경고 표시 (막지는 않고 경고만)
- 매도 수량 > 보유수량 시 오류

## 9. 투자자 컨텍스트 (판단 시 참고)

- **투자자:** 리스탈 (초보, 기준비중 30%)
- **슬롯:** 200만원 (1% = 2만원)
- **일 최대 매수:** 4% = 80,000원 (이월 불가)
- **현재 포지션:** 1주 × 11,960원 (비중 0.6%)
- **상추훈련 규칙:**
  - 수익 +1% 이상 시 최소 1% 매도
  - 매일 A(관찰) / B(분할매수) / C(매도섞기) 선택
  - 매수 전 3계산: 평단변화 / 비중변화 / 기준비중 대비
